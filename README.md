# 🌱 Automatic-Plant-Watering-System
An Arduino-based automatic irrigation system designed to monitor soil moisture and automatically water plants when the soil becomes dry.

📌 Project Overview

This project uses an Arduino microcontroller, soil moisture sensor, and water pump to automate plant watering. It monitors soil moisture levels and activates the water pump when the soil moisture falls below a defined threshold.

⚙️ Features
- Real-time soil moisture monitoring
- Automatic water pump activation
- Arduino based control system
